Privacy policy

PGCP Doc Verification · last updated 29 September 2026

What this tool does with Google data

The tool connects to one Google Drive account, belonging to the admissions team, in order to keep an archive of accepted admission documents. It uses Google's drive.file permission, which lets it create folders and files and read back only the files it created itself. It cannot see, read or change anything else in that Drive.

What is stored, and where

  • Copies of documents that candidates uploaded and admissions staff accepted, stored in that Drive in one folder per admission batch and one per candidate.
  • In the tool's own database: the identifier of each copied file and where it was placed, so the same document is never copied twice.

The tool stores no other Google account data. It does not read the account's email, contacts, calendar or any other file.

Who can see it

Only the owner of the connected Drive account, the admissions staff that owner shares the folder with, and the tool itself. Nothing is sold, shared with third parties, or used for advertising.

How long it is kept

Documents are kept for as long as the admissions team is required to retain admission records, and are then deleted from the Drive by that team.

Removing access

The Drive owner can revoke the tool's access at any time from myaccount.google.com/permissions. Revoking it stops further copying; files already archived stay in the Drive until the owner deletes them.
